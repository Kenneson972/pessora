Galerie sur les pages publiques

Quand un produit a plusieurs images, comment les afficher sur DrinkDetail / GammeProductDetail ?

A

Thumbnails cliquables sous le hero

Clic sur thumbnail → remplace l'image principale

+ Classique e-commerce · visible d'emblée
− Prend de la place si peu d'images

B

Galerie en dessous du bloc infos

Section "Photos du produit" après le hero split

+ Ne perturbe pas le hero · galerie plus grande
− Nécessite de scroller pour voir

C

Pas d'affichage public — admin seulement

La galerie sert uniquement à l'admin pour gérer plusieurs photos. Sur la page publique, seule image_url (le hero) est affiché.

+ Zéro changement sur les pages publiques
− Les images supplémentaires ne servent à rien pour les clients
