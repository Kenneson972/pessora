Où placer le bouton "✏️ Modifier" ?

Visible uniquement quand un admin est connecté. Quelle option te convient le mieux ?

Mode admin

A — Barre admin en haut

Une fine barre verte en haut de page avec le bouton Modifier. Clair, non intrusif pour le contenu.

B — Bouton flottant (coin bas droit)

Bouton fixe en bas à droite, visible en scrollant. Discret, ne perturbe pas la lecture.

C — Inline à côté du titre

Le bouton est placé juste à côté du nom du produit. Contextuel, on sait exactement ce qu'on modifie.
